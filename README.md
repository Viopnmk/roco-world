# roco-world

《洛克王国：世界》AI对战助手，阵容分析与回合策略

从零自建的《洛克王国：世界》图鉴与对战工具：数据管道、数据格式、页面代码全部自产。

## 数据来源

- BWIKI《洛克王国：世界》百科（wiki.biligame.com/nrc）社区维护的公开图鉴数据。
- 精灵数值、技能、进化关系等为游戏公开数据；本站只做整理与呈现。

## 数据管道（scraper/）

数据源不在百科页面正文里，而是存放在 Lua 数据模块中，分基础层与赛季层（S5）两层。管道分两步：

```bash
# 1. 拉取原始数据模块到 scraper/raw/（带断点续拉与重试）
python3 scraper/fetch_nrc.py

# 2. 解析 Lua 表、解码赛季分片、按 key 合并，生成站点数据
python3 scraper/build_data.py
```

- `scraper/lua_parse.py`：Lua 表字面量解析器（数据模块是 `return { ... }` 形式）。
- `scraper/fetch_nrc.py`：通过 MediaWiki API 拉取 15 个数据模块。
- `scraper/build_data.py`：合并规则与 BWIKI 自身的赛季适配器一致（赛季数据按 key 覆盖/追加基础层；SeasonLearnsets 给旧精灵追加赛季技能石）。
- `scraper/fetch_typechart.py`：单独拉取克制计算器的数据模块 `模块:Pets/data/Types`，转置并校验后生成 `web/data/typechart.json`（见「对战与配队」一节）。

## 数据格式（web/data/）

由管道生成、供页面直接读取的 JSON，字段口径自定：

- `pets.json`：精灵。每条含图鉴编号、显示名、物种名、属性、六维种族值与总和、特性、身高体重、图鉴描述、栖息地、赛季、拼音搜索键、头像/立绘文件名，以及学习面（等级技能 / 技能石 / 血脉技能，均为技能名）。
- `skills.json`：被精灵引用的技能与特性。含属性、分类（物理 / 魔法 / 变化 / 特性）、威力、能耗、描述。
- `evolutions.json`：进化链。含各阶段精灵、进化等级、特殊进化条件与首领化分支。
- `typechart.json`：属性克制表。`{攻方属性: {守方属性: 倍率}}`，18×18 全格，由 `scraper/fetch_typechart.py` 从 BWIKI 克制计算器的数据模块生成（见下「对战与配队」）。

当前数据量（2026-11-17 管道实跑）：精灵 662、技能与特性 861（招式 599 + 特性 262）、进化链 340。

## 图鉴本体（web/）

单文件 SPA（`web/index.html`，内联 CSS/JS、无外部依赖、无框架），静态托管即可运行，Hash 路由：`#/` 为列表、`#/pet/<id>` 为详情、`#/battle` 为对战模拟、`#/team` 为 AI 配队。顶部导航三页互通，详情页可一键把精灵送进对战或配队。

- **列表页**：按名字 / 物种 / 拼音 / 编号即时搜索；18 种属性 chips 单选筛选；赛季筛选（全部 / S1–S5 / 无赛季）；排序（图鉴编号、总和升降、六维各自降序）；卡片网格（头像、编号、属性徽章、总和），图片懒加载。
- **详情页**：立绘大图、种族值六维条形图、特性名与描述、身高 / 体重 / 栖息地 / 图鉴描述；进化链（含首领化分支，同 key 的多条分支记录在前端按 pet 去重合并展示）；技能表分等级技能 / 技能石 / 血脉技能三组，点行展开描述，属性 / 分类 / 威力 / 能耗均查自 `skills.json`。
- **图片**：`scraper/fetch_images.py` 通过 MediaWiki API 把头像 / 立绘文件名批量解析成 patchwiki 直链，生成 `web/data/images.json`（1264 个文件、662 只 × 头像+立绘全覆盖）。前端优先用直链，缺失或加载失败时回退 `Special:FilePath`，再失败显示首字占位块。图片有更新时重跑：

```bash
python3 scraper/fetch_images.py
```

本地预览：

```bash
cd web
python3 -m http.server 8000
# 浏览器打开 http://localhost:8000/
```

## 对战与配队（第 3 期）

页面在同一个 `web/index.html` 里：`#/battle` 对战模拟、`#/team` AI 配队，逻辑全部自写。

### 属性克制表（web/data/typechart.json）

- 来源：BWIKI「克制计算器」背后的结构化数据模块 `模块:Pets/data/Types`（BWIKI 的 `Module:TypeData` 从该模块组装计算器，模块注明按当前游戏数据生成）。用 `python3 scraper/fetch_typechart.py` 拉取并转置成攻方导向矩阵，原始模块缓存在 `scraper/raw/模块_Pets_data_Types.txt`。
- 本作的倍率只有四档：克制 ×2、双重克制 ×3、抵抗 ×0.5、双重抵抗 ×0.25。**没有属性免疫（不存在 ×0）**：例如电打地、幽灵打普通都只是 ×0.5，与经典宝可梦克制表不同，一律以本模块数据为准。
- 双系合并用「步进规则」：每个守方属性贡献一步（被克制 +1、被抵抗 −1），合计 +2→×3、+1→×2、0→×1、−1→×0.5、−2→×0.25。该规则已用模块自带的 102 条双系组合（1836 格）全量验证、零误差；模块未收录的组合（如毒+幻）也按此规则计算。
- BWIKI 的「幽系」在本站统一写作「幽灵」。

### 对战模拟（#/battle）

- 选攻方精灵 → 从它 learnset 全部技能（去重）里选一招 → 选守方精灵，即时算伤害；结果含克制倍率、本系加成、伤害占守方体力种族值的百分比与预计击破次数、每点能耗伤害。
- **伤害公式（估算口径）**：`伤害 = 威力 ×（攻击种族值 ÷ 防御种族值）× 克制倍率 × 本系加成`。物理技能用物攻/物防，魔法技能用魔攻/魔防；本系加成 = 技能属性与攻方任一属性一致时 ×1.2，否则 ×1。变化类技能显示「无直接伤害」并展示技能描述。
- 假设与局限：BWIKI 未公开本作完整伤害公式，以上为本站自定的透明估算口径；只用种族值，不含等级、个体值、特性与状态增减，结果仅供配招参考。

### 6v6 PVP 分析（#/battle 上方页签，默认页）

对战页上方有页签切换：「6v6 分析」（默认）与「1v1 计算」（即上面的对战模拟，原样保留）。6v6 分析把单挑计算器升级为整队对局分析：

- **队伍互通**：我方 / 敌方各最多 6 只，与配队页共用同一份本机存档（`localStorage` 键 `roco-world-team-v1`，同一组 `team.mine / team.foe` 数据）——配队页组好的队伍到对战页直接能用，反之亦然。不满 6 只也能分析，按现有只数计算并给出提示。
- **出招口径（代表招）**：每只精灵对每个目标，从其全部可学技能（等级 / 技能石 / 血脉三组去重）里按与 1v1 完全相同的伤害公式逐招计算，取伤害最高的一招为代表招；物理 / 魔法按技能分类取对应攻防，变化类等无威力技能不参与。
- **对位矩阵**：6×6 表格（我方行 × 敌方列），每格为代表招伤害占目标体力种族值的百分比与击杀标记（1 击 / 2 击 / 3 击+），按 ≥100% / 50–99% / <50% 三档配色，手机上可横滑；另附反向小结：敌方每只对我方的最高单体伤害 % 与能 1–2 击带走我方的只数（按威胁排序）。
- **胜负预测**：总判定（我方优势 / 均势 / 敌方优势）+ 我方倾向百分比，由四项按权重加权合成——击杀覆盖 35%（双方各有几只处于对方 2 击斩杀线内）、速度控制 20%（均速份额，附速度线逐位先手数）、种族值总和 20%（平均总和份额）、属性压制 25%（与配队页「对敌压制」同一口径）。每项附对比条与一句话解释。
- **文字分析**：模板化生成的中文分析师点评，全部引用真实计算数字：总体判断、我方王牌（对敌总威胁最高者及它能带走的名单）、最大威胁（敌方最危险者及受威胁名单）、应对建议（针对每只高威胁敌方，给出能反手 1–2 击带走它且挨打最轻的我方应对者）、首发建议（速度 + 覆盖综合最优者及理由）。
- **性能**：36 个对位 × 每对位遍历攻方全部可学技能，本机实测分析耗时约 5ms，手机上秒出；不做任何指数级搜索。

### AI 配队（#/team）

- 我的队伍最多 6 只（搜索加入、可移除，`localStorage` 保存在本机）；可选填敌方队伍（最多 6 只）。
- 评分 0–100，全部为自写规则，每项附人话解释：
  - **打击面覆盖**（无敌方时权重 35%）：全队有威力技能的属性集合，对 18 种单系守方逐一取最高克制倍率；每克制（×2 起）一种记满分、等倍一种记三成、被抵抗记 0 分（全克制 100 分、全等倍 30 分）。
  - **防御抗性**（30%）：弱点重叠（被同一属性克制的只数越多扣越狠，占 60 分）+ 人均弱点数（占 40 分）。
  - **种族值总和**（20%）：全队平均总和，按全图鉴极值（最低～最高）线性归一。
  - **速度线**（15%）：平均速度占 70% + 最快速度占 30%，均按全图鉴最快速度归一。
  - **对敌压制**（仅填敌方时计入，权重改为 打击面 25% / 防御 25% / 种族值 15% / 速度 10% / 对敌 25%）：我方打敌方每只的平均最高倍率与敌方反打我方的平均最高倍率之差，`50 +（我方 − 敌方）× 50` 截断到 0–100。
- **补位推荐**：队伍不满 6 只时，遍历全图鉴逐只试补、重算总分，取提升最大的 5 只；理由优先写新增的超效打击面与堵住的半伤短板，其次写抗性摊薄或面板/速度拉升。队伍满员时改为提示现存打击面短板。
